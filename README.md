# Rich Text Editor ✍️

A simple web-based Rich Text Editor built with HTML, CSS and JavaScript.  
Live demo: [https://rich-texteditor.netlify.app/](https://rich-texteditor.netlify.app/) 🚀

## 🎯 Features

- Basic formatting: **bold**, *italic*, _underline_, ~~strikethrough~~  
- Text alignment: left, center, right, justify  
- Lists: ordered lists and unordered lists  
- Headings & paragraphs: support for headings (H1–H6) and paragraphs  
- Font size adjustment  
- Text color and background highlight color  
- Insert / remove links  
- Undo / redo operations  
- Export content as **.txt** or **.pdf**  
- Toggle between WYSIWYG editor and raw HTML code view  

## 💻 How to Use

1. Open `index.html` in your browser  
2. Use the toolbar to format your text  
3. To export your document:  
   - Choose **Save as text** to download a `.txt` file  
   - Choose **Save as Pdf** to download a `.pdf` version  
4. Click the `</>` button to view or edit raw HTML  

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript (vanilla JS)  
- [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) for PDF export
